# OxiCut website

The homepage for [OxiCut](https://github.com/oxicut/oxicut), served by GitHub Pages. Plain HTML and one stylesheet, no build step: open `index.html` in a browser to see it.

The people it is written for are not technical, so keep the words plain, the type large and the page short. The colours match the app (`style.css`).

## Files

- `index.html`: the start page with the download button, three steps and a few questions.
- `install.html`: what to expect when Windows warns about a new installer.
- `style.css`, `favicon.ico`.
